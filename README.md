Лабораторна робота № 9
ТЕМА: Опрацювання однозв'язних списків.
МЕТА: Набути практичних навичок створення та застосування однозв'язних списків за допомогою контейнера `forward_list` у мові програмування C++.
---
Завдання 1
Умова: Створити однозв'язний список із дійсних чисел. Видаліть елемент списку перед кожним числом 55.
Опис рішення
Оскільки контейнер `std::forward_list` підтримує ітерацію лише в одному напрямку (вперед), видалення попереднього елемента "на льоту" ускладнене. Тому для вирішення задачі створюється новий результуючий список. Елементи додаються туди за допомогою `push_front()`. Якщо поточний елемент дорівнює `55.0`, останній доданий елемент (який є попереднім у початковому списку) видаляється за допомогою `pop_front()`. Наприкінці використовується метод `reverse()`, щоб відновити правильний порядок елементів.
Код програми
```cpp
#include <iostream>
#include <forward_list>

using namespace std;

int main() {
    // Створюємо початковий список
    forward_list<double> numList = {10.5, 20.1, 55.0, 30.2, 40.4, 55.0, 15.0};
    
    cout << "Початковий список: ";
    for (double num : numList) {
        cout << num << " ";
    }
    cout << endl;

    forward_list<double> result;
    
    // Перебираємо елементи початкового списку
    for (double num : numList) {
        if (num == 55.0 && !result.empty()) {
            result.pop_front(); 
        }
        result.push_front(num);
    }

    // Відновлюємо правильний порядок
    result.reverse();

    cout << "Список після видалення елементів перед числом 55: ";
    for (double num : result) {
        cout << num << " ";
    }
    cout << endl;

    return 0;
}
```

Завдання 2
Умова: Створити список оцінок студентів. Додайте кілька елементів на початок списку, потім видаліть першу оцінку і знайдіть середнє значення.
Опис рішення
Для зберігання оцінок використовується `std::forward_list<int>`. Додавання нових елементів на початок реалізовано методом `push_front()`, а видалення першого елемента — методом `pop_front()`. Для знаходження середнього значення використовується цикл `for` (range-based), у якому підраховується загальна сума оцінок та їх кількість.
Код програми
```cpp
#include <iostream>
#include <forward_list>
#include <iomanip>

using namespace std;

int main() {
    // 1. Створити список оцінок студентів
    forward_list<int> grades = {85, 90, 78};

    // 2. Додати кілька елементів на початок списку
    grades.push_front(92);
    grades.push_front(88);
    grades.push_front(75);

    cout << "Список оцінок після додавання нових: ";
    for (int grade : grades) {
        cout << grade << " ";
    }
    cout << endl;

    // 3. Видалити першу оцінку
    if (!grades.empty()) {
        grades.pop_front();
    }

    cout << "Список оцінок після видалення першої: ";
    for (int grade : grades) {
        cout << grade << " ";
    }
    cout << endl;

    // 4. Знайти середнє значення
    double sum = 0.0;
    int count = 0;

    for (int grade : grades) {
        sum += grade;
        count++;
    }

    if (count > 0) {
        double average = sum / count;
        cout << "Середнє значення оцінок: " 
             << fixed << setprecision(2) << average << endl;
    } else {
        cout << "Список порожній, середнє значення обчислити неможливо." << endl;
    }

    return 0;
}
```
